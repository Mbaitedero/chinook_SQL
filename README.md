# Exercices SQL — Base Chinook

Série d'exercices SQL réalisés sur la base de données d'exemple **Chinook** (ventes de musique en ligne), couvrant les requêtes de base jusqu'aux analyses agrégées plus avancées.

## 📂 Contenu

| Fichier | Thème |
|---|---|
| `Requêtes de base.sql` | Filtres simples (clients non américains, clients brésiliens...) |
| `Agrégations et relations.sql` | Jointures entre clients, factures et agents de vente |
| `Analyse par année et lignes de facture.sql` | Ventes par année, nombre d'articles par facture |
| `Détails des morceaux.sql` | Jointures morceaux / artistes / albums |
| `Comptages et regroupements.sql` | `GROUP BY` : factures par pays, morceaux par playlist |
| `Analyse des ventes.sql` | Meilleurs agents de vente par année |
| `Analyse des clients et des pays.sql` | Ventes totales par pays, clients par agent |
| `Analyse des morceaux et des artistes.sql` | Top morceaux et artistes les plus vendus |
| `Create_Table.sql` / `Insertion.sql` | Scripts de création et d'alimentation de la base |

## 🛠️ Compétences mobilisées

`SELECT`, `WHERE`, `JOIN`, `GROUP BY`, `HAVING`, fonctions d'agrégation (`SUM`, `COUNT`, `AVG`), sous-requêtes.
